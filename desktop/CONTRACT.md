# Desktop module contract

All data is local. No network clients, corporate fixtures, employee PII, or real company figures.

## Importer (pno/importer.py)

`scan_workbook(path, kind=None, period=None, mappings=None) -> ImportPlan`

ImportPlan: dataclass with `path: str`, `checksum: str`, `candidates: list[Candidate]`, `warnings: list[str]`.
Candidate: dataclass with `kind: str`, `sheet: str`, `header_row: int` (1-based), `records: list[dict]`, `warnings: list[str]`, `confidence: float`, `column_map: dict[str,str]`.
Kinds: roster, attendance, sales_daily, sales_mtd, productivity. Unknown candidates require a manual kind.
Records use canonical keys where identifiable, preserve unknown source columns under `raw`. Common keys: store, department, section, employee_id, employee_name, designation, grade, gender, manager_id, manager_name, date, status, in_time, out_time, hours, actual, budget, last_year, oos_value, oos_pct, productivity, productivity_ly, productivity_growth.
Do not manufacture metrics. Do not sum detail and summary rows. Preserve absence statuses and numeric zero. Percentage values must be percentage points (0.05 formatted as % in Excel -> 5.0).
`mappings` maps exact original header strings to canonical keys; explicit overrides win.

## Store (pno/storage.py)

`Store(path)` initializes/version-checks SQLite. `Store.default_path() -> Path` is outside the executable in OS user-data dir; override via PNO_DATA_DIR.
`import_records(kind, period, records, source, checksum, sheet, replace=False) -> int` atomic; identical active checksum/sheet/kind/period raises DuplicateImportError. Same scope+period conflicts raise ConflictImportError unless explicit replace. Replaced batches retained but inactive.
`list_imports() -> list[dict]` id, kind, period, source, checksum, sheet, created_at, count, active.
`records(kind=None, period_from=None, period_to=None, store=None, department=None, section=None, employee=None) -> list[dict]` returns ACTIVE records only with `_period`, `_import_id`, `_kind`, `_source`, `_sheet`. Date filters use actual record date where present, otherwise batch period.
`dimensions() -> dict[str,list[str]]` stores, departments, sections from active data.
`employees(period=None) -> list[dict]` latest roster snapshot per store as-of period, unique employee_id; direct reports by manager_id (do not compare by names).
`backup(path)` SQLite backup API. `restore(path)` validate database schema/integrity first, preserve pre-restore backup, then restore atomically. No raw workbook copies by default.

## Analysis (pno/analysis.py)

`analyze(store, filters=None) -> dict` filters: kind ('sales_mtd' default), period_from, period_to, store, department, section, employee.
Result keys: metrics (dict), commentary (list[str]), warnings (list[str]), trends (list[dict]), rows (list[dict]), sources (list[dict]), score (dict).
metrics keys: actual, budget, last_year, budget_achievement_pct, sales_growth_pct, oos_value, oos_pct, attendance_rate_pct, hours, employee_count, direct_reports, productivity. Missing is None.
Manager scope resolved from as-of roster; employee sales only for designated managerial role, not ordinary staff.
Score is explainable PROVISIONAL, missing metrics never zero; no score without approved full criteria; expose component evidence.
`export_report(result, path, format='pdf', filters=None)` PDF, xlsx or csv supported, includes provenance/filters/warnings.

## Assistant (pno/assistant.py)

`Assistant(store, model_path=None).ask(question, filters=None) -> str`.
Offline controlled query interpreter/rule commentary always available and clearly labeled, optional local GGUF via llama_cpp only if installed AND selected, max 1GB weights. User-visible model errors; no arbitrary SQL/tools generated by model, no cloud/API/download.

## Desktop UI (pno/ui.py)

`MainWindow(store)`; launch via python -m pno. Dashboard, Imports & History, Sales, Attendance, Staff & Hierarchy, Analyze, Assistant, Settings. Brown #31261D gold #B5975A white. All UI uses contract above.
Imports: file picker + pasted TSV/CSV, period and kind, multi-sheet preview with candidate selection and column mapping, warnings, save selected with explicit correction confirmation. Background work for scan/import/LLM. Daily/MTD distinguished.
Filters/search; date/calendar history; as-of staff; charts; PDF/Excel export; backup/restore; model selection. Empty states honest. No synthetic auto-seeded production data.
